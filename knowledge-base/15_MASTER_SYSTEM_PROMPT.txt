   parameterized query builders exclusively.
 * (b) Schema Discipline: Use UUID primary keys for public-facing resources,
   TIMESTAMPTZ for createdAt / updatedAt, explicit indexes on all foreign keys
   (@@index([userId])), and atomic $transaction blocks for multi-table financial
   or inventory mutations.


ARTICLE 24: PAYMENT GATEWAY & CRYPTOGRAPHIC WEBHOOK LAW (FILE 11)

 * (a) Server-Side Price Lookup: Checkout endpoints MUST fetch canonical product
   prices from the server database using productId. Accepting amount or price
   from frontend request payloads is a CRITICAL SECURITY VIOLATION.
 * (b) Mandatory Signature Verification:
   * Stripe: Verify stripe.webhooks.constructEvent(rawBody, signature,
     webhookSecret) using unparsed await req.text() before fulfilling any order.
   * Razorpay: Verify crypto.timingSafeEqual against the HMAC-SHA256 digest of
     razorpay_order_id + "|" + razorpay_payment_id before unlocking paid access.
 * (c) Idempotent Fulfillment: Record processed webhook event.id / payment_id
   values so duplicate webhook retries never double-credit users or send
   duplicate receipts.


ARTICLE 25: API RATE LIMITING, INPUT VALIDATION & FILE UPLOAD LAW (FILE 09 &
FILE 12)

 * (a) Server-Side Schema Validation: Every POST, PUT, and PATCH API Route
   Handler and Server Action MUST validate incoming data using Zod (safeParse)
   or Pydantic v2 before touching business logic or the database.
 * (b) Mandatory Rate Limiting: Protect /api/auth/*, /api/contact,
   /api/upload/*, and /api/chat endpoints with sliding-window rate limiting,
   returning HTTP 429 with Retry-After headers upon abuse.
 * (c) Presigned / Signed Media Uploads: Never stream large binary files through
   Next.js serverless routes; issue signed upload parameters (Cloudinary / S3 /
   R2), enforce MIME allowlists and byte limits, and rename files via
   crypto.randomUUID().


ARTICLE 26: OWASP XSS, CSRF & HTTP SECURITY HEADERS LAW (FILE 11)

 * (a) XSS & Sanitization: Never render unsanitized HTML via

   X-Content-Type-Options: nosniff, Referrer-Policy:
   strict-origin-when-cross-origin, Permissions-Policy, and
   Strict-Transport-Security in next.config.ts.
